# lstsportaldarkmode
simple dark mode for lsts portal
## Installation/ How to use
### 1. Install the Extension
1. **Extract the archive:** Right-click the downloaded `.zip` file and select **Extract All...** (Windows) or double-click it (Mac) to unzip it into a standard folder. 
2. **Open your Extensions page:**
   - **Chrome / Brave:** Type `chrome://extensions/` in your address bar.
   - **Edge:** Type `edge://extensions/` in your address bar.
3. **Enable Developer mode:** Toggle the switch (usually located in the top-right or bottom-left corner).
4. **Load the extension:** Click the **Load unpacked** button and select the *extracted folder* (make sure you select the folder containing the `manifest.json` file, not the `.zip` file itself).

### 2. How to Use
- **Automatic:** Simply navigate to `portal.lsts.edu.vn`. The dark mode engine applies instantly before the page fully loads, preventing any blinding white flashes.
- **Manual Toggle:** Press **`Alt + D`** at any time while on the LSTS portal to quickly switch between your custom dark theme and the original light theme.

### 3. Updating the Extension
If you receive a new `.zip` file with updates in the future:
1. Delete the old extracted folder and extract the new `.zip` in its place.
2. Go back to your browser's extensions page.
3. Click the **Reload icon** (`⟳`) on the LSTS Portal Dark Mode card.
4. Hard refresh your portal tab (`Ctrl + Shift + R` or `Cmd + Shift + R`) to see the changes.
